# 日本語 — публикация команды

Веб-приложение: React + TypeScript + Vite, устанавливаемая PWA.
Windows: Electron. Android и iOS: Capacitor.
Учебный прогресс: локальные события в localStorage; интервальные повторения FSRS.
Словарь: локальный JMdict в Web Worker. Письмо кандзи: проверка геометрии KanjiVG.
Код будущей синхронизации: Supabase; в альфе отключён.

## GitHub Pages

На бесплатном тарифе нужен публичный репозиторий. При публикации исходников
они становятся доступными для просмотра; само по себе это не выдаёт лицензии
на произвольное использование нашего кода. Лицензии сторонних компонентов
сохраняются в THIRD_PARTY.md и файлах поставки.

В Settings → Pages выберите GitHub Actions. При обновлении ветки main
процесс .github/workflows/pages.yml проверяет и публикует веб-приложение.
Поддерживаются как корневой домен, так и адрес /имя-репозитория/.

APK, EXE и исходный проект iOS размещаются отдельно в GitHub Releases.
Большой EXE не следует добавлять в обычную историю репозитория.

Нельзя публиковать private/, .env, ключи подписи, личные учебники, книги,
резервные копии прогресса, work/, node_modules/ и старый checkout хостинга.
Ключ подписи Android хранится только локально: он нужен для совместимых обновлений.

## Перенос данных

Перед сменой адреса сохраните резервную копию в настройках старого сайта.
На новом сайте восстановите её. Браузер не переносит localStorage между доменами.
На iPhone старый ярлык нужно заменить новым после проверки переноса данных.
Старую публикацию не отключаем до проверки новой.
